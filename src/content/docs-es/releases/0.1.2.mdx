## Los errores operativos siguen siendo errores

`ach verify` ya no imprime `proof invalid` cuando no puede abrir o inspeccionar
un archivo de prueba, inputs publicos o verification key. El comando termina
con la causa precisa, de modo que un script puede distinguir una falla
operativa de una prueba criptograficamente invalida.

## Un solo contrato de salida JSON

La bandera global `--error-format json` ahora selecciona salida JSON para la
verificacion separada cuando se omite `verify --format`:

```bash
ach --error-format json verify \
  --proof proof.json \
  --public public.json \
  --vkey verification_key.json \
  --curve bn254
```

Un `verify --format text` o `verify --format json` explicito conserva la
precedencia. Las pruebas invalidas y los errores operativos mantienen status
distinto de cero en ambas representaciones.
