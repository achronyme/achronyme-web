## Estado de versiones

El último release publicado del editor es `0.2.0`. Editor `0.3.0` es el
candidato para Achronyme core `0.1.0` y fija la revisión exacta
`fd07b38e16256e2ed6a8f2b438d340a681c9b0ac`.

Usa los [releases publicados del editor](https://github.com/achronyme/achronyme-editor/releases)
para una instalación normal. Compila el candidato desde source solo cuando
también estés evaluando el candidato 0.1.0 del core.

## Features de VS Code

El candidato 0.3.0 proporciona:

- Resaltado TextMate para `.ach`, incluyendo `concurrent`, `spawn`, `await`,
  task calls e I/O de archivo o red basado en capacidades.
- Activación y resaltado del lenguaje Circom para `.circom`.
- Diagnósticos respaldados por el parser mientras escribes.
- Tokens semánticos para declaraciones, task handles, async calls, builtins,
  parámetros, tipos, métodos, strings, números y operadores.
- Hover para keywords, funciones globales, métodos y namespaces estáticos.
- Completion para 30 keywords, 43 funciones globales, 47 métodos, 6 miembros
  de namespaces estáticos y 16 snippets.
- Símbolos de documento, go-to-definition, referencias y rename.
- Botón Run que invoca `ach run` en una terminal integrada.
- Descubrimiento, descarga y avisos de actualización del CLI desde releases
  publicados del core.

Formatting no está implementado en esta línea.

## Compilar el candidato 0.3.0

```bash
git clone https://github.com/achronyme/achronyme-editor.git
cd achronyme-editor
git checkout release/0.3.0

cargo build --release -p ach-lsp
mkdir -p editors/vscode/bin
cp target/release/ach-lsp editors/vscode/bin/

cd editors/vscode
npm ci
npm run build
npm run typecheck
npm test
```

Abre un Extension Development Host:

```bash
code --extensionDevelopmentPath=editors/vscode
```

## Comportamiento de versión del CLI

La extensión busca `ach` en este orden:

1. `achronyme.executablePath`;
2. la ubicación de descarga administrada por la extensión;
3. el `PATH` del sistema.

Las descargas vienen del último release **publicado** del core en GitHub. Hasta
publicar `v0.1.0`, la descarga automática instala core `0.0.1`, no el candidato
del source.

## Settings

| Setting | Default | Descripción |
|---|---|---|
| `achronyme.executablePath` | `""` | Path al CLI `ach`. Vacío habilita descubrimiento bundled, administrado o por `PATH`. |
| `achronyme.lspPath` | `""` | Path a `ach-lsp`. Vacío usa el binario incluido con la extensión. |

## Otros editores

`ach-lsp` se comunica por stdio mediante Language Server Protocol. Editores
como Neovim, Helix y Zed pueden lanzar el binario directamente. La extensión de
VS Code agrega administración de descargas y el comando Run; esas features no
forman parte del servidor de protocolo.
