## Instalación Rápida

Instala el ultimo release **publicado** del core con un solo comando:

```bash
curl -fsSL https://achrony.me/install.sh | sh
```

Esto instala `ach` en `~/.local/bin`. En Linux, el bundle verificado tambien
instala el runtime AOT nativo en `~/.local/lib`. El instalador funciona en
Linux y macOS sobre x86_64 y aarch64.

La version estable publicada actualmente es `0.1.1`. Fijala de forma explicita
cuando la reproducibilidad importe:

```bash
curl -fsSL https://achrony.me/install.sh | sh -s -- --version 0.1.1
```

Verifica la instalación:

```bash
ach --version
```

En Linux, `ach run` usa LLVM 21 cuando esta disponible. Si LLVM no esta
instalado, el CLI informa el fallback y ejecuta el interprete. La compilacion
nativa con `ach aot` requiere Clang 21 y LLVM 21; el instalador ya incluye la
biblioteca de runtime AOT de Achronyme.

## Compilar 0.1.1 desde source

Achronyme esta escrito en Rust. El toolchain del release es Rust 1.96.0. Usa la
revision publicada exacta al reproducir el comportamiento de 0.1.1:

```bash
git clone https://github.com/achronyme/achronyme.git
cd achronyme
git checkout b1774e88671a1889146804cb812cb099eb9cc006
cargo build --release
target/release/ach --version
```

El binario se encuentra en `target/release/ach`.

### Verificar la compilación

```bash
cargo test --workspace
bash test/run_tests.sh
```

## Opcional: Compatibilidad con snarkjs

Achronyme incluye backends nativos de Groth16 (ark-groth16) y PlonK
(halo2-KZG). En 0.1.1, generar pruebas falla si no eliges
`--insecure-dev-setup` o `--trusted-key-dir`. Las herramientas externas no son
necesarias para ejecucion normal, pero snarkjs sigue siendo parte de la
ceremonia de produccion y la auditoria de interoperabilidad.

Los archivos `.r1cs` y `.wtns` generados también son compatibles con snarkjs para flujos de trabajo externos:

```bash
snarkjs groth16 setup circuit.r1cs pot12_final.ptau circuit.zkey
snarkjs groth16 prove circuit.zkey witness.wtns proof.json public.json
snarkjs groth16 verify verification_key.json public.json proof.json
```
